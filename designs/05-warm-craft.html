tether

Durable memory for AI agents.

An MCP server backed by one local SQLite file, so what an agent learns about you survives the session it learned it in.

Spec

  • v0.5.1
  • Python
  • MCP
  • SQLite / FTS5
  • libSQL / Turso
$ claude mcp add tether -- uvx tether-memory
  • Repository →
  • PyPI · tether-memory →
  • Four verbs remember, recall, link, forget.
  • Local-first One SQLite file, zero configuration, nothing leaves the machine.
  • Hybrid recall FTS5 keyword hits fused with local semantic vectors, so “automobile” finds your note about a car.
  • Optional sync Point it at libSQL/Turso and the same file becomes an embedded replica across every device.
  • Associative graph Related memories surface along three edge types: semantic, explicit link(), and hebbian.
  • Hebbian edges Memories recalled together get wired together over time.

66.9KB→2.0KB A recall response, once it returns query-centred excerpts instead of full bodies.

Every hit reports which edge it came down. The via receipt, carried on every result.

Five more, on how it behaves over time
  • Seed-dominant Associations fill the slots below direct hits, never demoting a good one.
  • Self-organizing A hub-curated boot index surfaces load-bearing memories, and nothing is ever hard-deleted.
  • Crystallization It spots dense memory clusters and offers them up to be named as principles.
  • Static embeddings The model is small and local, so there is no API key and no network call.
  • Degrades cleanly Every feature falls back to plain keyword recall.

02

cleat

A real terminal for AI agents.

A persistent shell behind a PTY that returns structured results — stdout, a real exit code, files touched — instead of escape-code soup.

Spec

  • Python
  • MCP
  • PTY / termios
  • OSC 133
  • pyte
$ claude mcp add cleat -- uvx cleat
  • Repository →
  • PyPI · cleat →
  • The problem A shell knows $? but never prints it, so scraping a PTY can’t recover it.
  • The fix cleat injects OSC 133 marks into the shells it spawns and parses them back out.
  • Persistent session cd, export, venvs and ssh all carry across calls.
  • State is read, not guessed It comes from termios flags and the foreground process group.
  • Password consent It refuses to type into a password prompt without a human go-ahead.
  • Nonce-signed marks A program can’t forge itself a clean exit code.
  • Spoof reporting A bad mark is ignored and surfaced as spoofed_marks.
  • Terminal-agnostic Not an emulator, and not a patch to yours.
{ "stdout": "...", "exit_code": 0,
  "completed": true, "state": "idle" }
What every call hands back.

The exit code isn’t in the stream at all. The reason this project exists.

The five states
StateWhat it meansWhat to do
idleSitting at a prompt.Send the next command.
runningA foreground process holds the terminal.Wait, or interrupt.
awaiting-inputA program is reading a line.Answer it.
passwordEcho is off; a secret is wanted.Ask the human first.
tuiA full-screen app owns the screen.Send keys, read the buffer.

Black Diamond Brawl

A downhill snowboarding combat racer.

Road Rash on a snowboard — one seeded procedural slope, a finish line, and rivals who’d rather you didn’t reach it.

Spec

  • v1 complete · 9 phases
  • v2 visual overhaul
  • Phaser 3
  • TypeScript
  • Vite
  • segment-based pseudo-3D
  • Repository →
  • Seeded slopes Every run is a fixed-length procedurally generated course ending at a finish line.
  • Trick air Moguls and hill crests launch you automatically at speed.
  • Combat mid-race Shove or ski-pole your way past AI rivals on the same course.
  • Scoring Finish fast, land hits, thread near-misses, stomp tricks.
  • Wipe out Crash hard before the line and the run ends early.
  • Pseudo-3D renderer Segment-based projection, the OutRun and Road Rash lineage.
  • Contrast build gate The build fails below ΔL* 12 on gameplay edges or ΔL* 25 on sprite outlines.
  • Headless sim Balance is verified by a seeded combat simulation, without a browser.

0 image files Every sprite and gradient in the repository is generated in code at boot.

Art in code, checked by the build. Colour here is a test that can fail, not a judgement call.
