No. 01 — Memory

Python · MCP · SQLite

tether

Durable memory for AI agents.

An MCP server backed by one local SQLite file, so what an agent learns about you survives the session it learned it in.

Specification
Statusv0.5.1 · released
Stack
  • Python
  • MCP
  • SQLite / FTS5
  • libSQL / Turso
  • Static embeddings
Packagetether-memory on PyPI
Installclaude mcp add tether -- uvx tether-memory
Repogithub.com/sidyellur/tether

Recall payload

66.9KB→2.0KB

After returning query-centered excerpts instead of full bodies.

Features

Eleven

Four verbs
remember, recall, link, forget.
Local-first
One SQLite file, zero configuration, nothing leaves the machine.
Hybrid recall
FTS5 keyword hits fused with local semantic vectors, so “automobile” finds your note about a car.
Optional sync
Point it at libSQL/Turso and the same file becomes an embedded replica across every device.
Associative graph
Related memories surface along three edge types: semantic, explicit link(), and hebbian.
via receipts
Every hit reports which edge it came down.
Five more
Hebbian edges
Memories recalled together get wired together over time.
Seed-dominant
Associations fill the slots below direct hits, never demoting a good one.
Self-organizing
A hub-curated boot index surfaces load-bearing memories; nothing is ever hard-deleted.
Crystallization
Detects dense memory clusters and offers them up to be named as principles.
Degrades cleanly
Every feature falls back to plain keyword recall.

No. 02 — Terminals

Python · MCP · PTY

cleat

A real terminal for AI agents.

A persistent shell behind a PTY that returns structured results — stdout, a real exit code, files touched — instead of escape-code soup.

Specification
StatusReleased · on PyPI
Stack
  • Python
  • MCP
  • PTY / termios
  • OSC 133
  • pyte
Packagecleat on PyPI
Installclaude mcp add cleat -- uvx cleat
Repogithub.com/sidyellur/cleat

The premise

The exit code isn’t in the stream at all.

{ "stdout": "...", "exit_code": 0,
  "completed": true, "state": "idle" }

Features

Nine

The problem
A shell knows $? but never prints it, so scraping a PTY can’t recover it.
The fix
cleat injects OSC 133 marks into the shells it spawns and parses them back out.
Persistent session
cd, export, venvs and ssh all carry across calls.
State is read, not guessed
Derived from termios flags and the foreground process group.
Nonce-signed marks
A program can’t forge itself a clean exit code.
Password consent
It refuses to type into a password prompt without a human go-ahead.
Three more
Five states
idle, running, awaiting-input, password, tui.
Spoof reporting
A bad mark is ignored and surfaced as spoofed_marks.
Terminal-agnostic
Not an emulator, and not a patch to yours.
Session states
StateWhat it meansWhat to do
idleShell is sitting at a promptSend the next command
runningA command is in flightWait, or send input
awaiting-inputA process is asking for a lineAnswer the prompt
passwordA secret is being asked forGet human consent first
tuiA full-screen program owns the screenSend keys, read the frame

Black Diamond Brawl

A downhill snowboarding combat racer.

Road Rash on a snowboard — one seeded procedural slope, a finish line, and rivals who’d rather you didn’t reach it.

Specification
Statusv1 complete · nine phases · v2 visual overhaul complete
Stack
  • Phaser 3
  • TypeScript
  • Vite
  • Segment-based pseudo-3D
ArtNo files on disk — generated in code at boot
Build gateFails below ΔL* 12 on gameplay edges, ΔL* 25 on outlines
Repogithub.com/sidyellur/black-diamond-brawl

Image files in the repo

0

Every sprite, gradient and weather effect is drawn by code.

Features

Nine

Seeded slopes
Every run is a fixed-length procedurally generated course ending at a finish line.
Trick air
Moguls and hill crests launch you automatically at speed.
Combat mid-race
Shove or ski-pole your way past AI rivals on the same course.
Scoring
Finish fast, land hits, thread near-misses, stomp tricks.
Art in code
Every sprite and gradient is generated at boot; no image files at all.
Pseudo-3D renderer
Segment-based projection, the OutRun and Road Rash lineage.
Three more
Wipe out
Crash hard before the line and the run ends early.
Contrast build gate
The build fails below ΔL* 12 on gameplay edges or ΔL* 25 on sprite outlines.
Headless sim
Balance is verified by a seeded combat simulation, without a browser.
