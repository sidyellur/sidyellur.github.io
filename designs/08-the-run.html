● Gate 01 · Green circle

Tooling for things that don’t remember

what I work on

Most of what I build sits one layer below the interesting part. An agent is only as good as what it can recall and what it can actually run, and both of those turn out to be much harder than they look from the outside.

tether gives an agent durable memory in a local SQLite file that can quietly become a synced replica across every machine you own. cleat gives it a real, persistent shell and a truthful answer about how a command ended. Both are MCP servers, both install in one line, and both are built to degrade rather than break.

Black Diamond Brawl is the opposite of unglamorous: a downhill snowboarding combat racer built solo, where every pixel is generated at boot and a build gate fails the whole thing if a tree stops being visible against the snow.

◆ Gate 02 · Black diamond

tether

a shared memory layer for personal agents · v0.5.1 · Python

An MCP server backed by a plain SQLite file. Any MCP-compatible agent can remember, recall, link and forget durable notes — facts about you, your projects, your preferences — so context follows you between sessions instead of dying with each one.

# install
claude mcp add tether -- uvx tether-memory

Why it’s interesting

  • Local-first, zero configuration. It runs entirely off one file on your disk. Point it at a hosted libSQL/Turso primary and that same file becomes an embedded replica — memory syncs across every device in near-real-time, and nothing about the local API changes.
  • Recall is hybrid. Keyword results from FTS5 are fused with semantic vector results, so “automobile” finds the note about your “car”. The embedding model is small and static and runs locally: no network call, no API key.
  • An associative usage graph. Hits pull in related memories along edges from three local, deterministic sources: semantic nearest-neighbours, explicit link() calls, and hebbian edges — memories recalled together get wired together over time. Every hit carries a via receipt explaining why it surfaced.
  • Recall is seed-dominant. Top direct matches are locked in place and associations only fill the slots below them. Turning association on can never demote a good hit — which is what makes the feature safe to leave switched on.
  • The store self-organizes. A hub-curated boot index surfaces load-bearing memories — the ones with the highest behavioral degree — alongside recent ones. An opt-in sweep soft-archives memories that are both old and behaviorally isolated. Nothing is ever hard-deleted.
  • Optional crystallization. It detects dense clusters of related memories and offers them up to be named as principles. tether finds the structure; the agent supplies the words.
  • Everything degrades cleanly to plain keyword recall. It is deliberately a convenience layer: more useful when present, never breaking the agent when degraded.

◆ Gate 03 · Black diamond

cleat

a headless terminal layer for AI agents · Python

cleat runs a persistent shell session behind a PTY, parses its byte stream for OSC 133 shell-integration marks, and exposes it to an agent over MCP as structured results — stdout, a real exit_code, the files that were touched — instead of raw escape-code soup.

# install
claude mcp add cleat -- uvx cleat

# what the agent actually receives
{ "stdout": "...", "exit_code": 0, "completed": true, "state": "idle" }

Why it’s interesting

  • The exit code isn’t in the stream at all. That is the core insight. A shell knows $? but never prints it, so no amount of scraping a PTY will recover it. cleat injects OSC 133 marks into the shells it spawns and parses them back out.
  • The session persists. cd, export, activated venvs and ssh sessions all carry across calls — something a fresh subprocess per command fundamentally cannot do.
  • State is read, not guessed. Every response carries a state derived from termios flags and the foreground process group: facts only the process holding the PTY can see, rather than inferences from output timing. The states are idle, running, awaiting-input, password and tui.
  • It refuses to type into a password prompt without explicit human consent.
  • Marks are nonce-authenticated. A command could print a fake OSC 133 sequence to its own stdout and forge a clean exit code. So each session gets a fresh secrets.token_hex(8) nonce embedded in every mark cleat injects; a mark with a missing or wrong k= is ignored outright and surfaced as spoofed_marks, so the agent can tell when a program lied about how it finished.
  • Terminal-agnostic. Not a terminal emulator, and not a modification to yours.

◆◆ Gate 04 · Double black diamond

Black Diamond Brawl

a downhill snowboarding combat racer · v1 complete, 9 phases · v2 visual overhaul complete

A Road Rash-style downhill snowboarding combat racer, built solo as a learning project. Each run is a single race down a fixed-length, seeded, procedurally generated slope, ending at a finish line.

Why it’s interesting

  • The run itself. Dodge trees, rocks and moguls. Catch trick air off moguls and hill crests — crests launch you automatically at speed. Shove or ski-pole your way past AI rivals racing the same course.
  • Scoring rewards commitment. Points come from finishing fast, landing hits on rivals, near-misses and tricks. Wipe out hard before the line and the run ends early.
  • A classic segment-based pseudo-3D renderer gives it the behind-the-rider, slope-rushing-at-you look — OutRun and Road Rash — with pixel art sprites. It is the same projection driving the mountain behind this page: a list of segments with world-space z, projected out to trapezoidal bands and painted back to front.
  • All art and atmosphere is generated in code at boot. There are no image files in the repository at all. Colour is governed by a palette module and enforced by a build gate that fails the build if any gameplay-relevant edge drops below ΔL* 12, or any sprite outline below ΔL* 25 against the snow behind it.
  • Balance is verified without a browser. It ships with a headless seeded combat simulation and a solvability model, so a course can be proven survivable before anyone plays it.
