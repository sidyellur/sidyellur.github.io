tether

Durable memory for AI agents.

An MCP server backed by one local SQLite file, so what an agent learns about you survives the session it learned it in.

Specification
Versionv0.5.1
LanguagePython
ProtocolMCP
StoreSQLite / FTS5
SynclibSQL / Turso
PyPItether-memory
Reposidyellur/tether
$ claude mcp add tether -- uvx tether-memory
Measured — recall response
66.9KB → 2.0KB

Recall returns query-centered excerpts now, instead of full bodies.

Matrix
Eleven behaviours
One label  ·  One sentence
Four verbs

The whole API is remember, recall, link and forget.

Local-first

One SQLite file, zero configuration, nothing leaves the machine.

Optional sync

Point it at libSQL/Turso and the same file becomes an embedded replica across every device.

Hybrid recall

FTS5 keyword hits are fused with local semantic vectors, so “automobile” finds your note about a car.

Associative graph

Related memories surface along three edge types: semantic, explicit link(), and hebbian.

Hebbian edges

Memories recalled together get wired together over time.

Via receipts

Every hit reports which edge it came down.

Seed-dominant

Associations fill the slots below direct hits, never demoting a good one.

Self-organizing

A hub-curated boot index surfaces load-bearing memories, and nothing is ever hard-deleted.

Crystallization

It detects dense memory clusters and offers them up to be named as principles.

Degrades cleanly

Every feature falls back to plain keyword recall.

cleat

A real terminal for AI agents.

A persistent shell behind a PTY that returns structured results — stdout, a real exit code, files touched — instead of escape-code soup.

Specification
LanguagePython
ProtocolMCP
KernelPTY / termios
MarksOSC 133
Screenpyte
PyPIcleat
Reposidyellur/cleat
$ claude mcp add cleat -- uvx cleat
The hook

The exit code isn’t in the stream at all.

Structured result
{ "stdout": "…", "exit_code": 0, "completed": true, "state": "idle" }

What the agent receives in place of raw bytes.

Matrix
Nine behaviours
One label  ·  One sentence
The problem

A shell knows $? but never prints it, so scraping a PTY cannot recover it.

The fix

cleat injects OSC 133 marks into the shells it spawns and parses them back out.

Persistent session

cd, export, venvs and ssh all carry across calls.

State is read

It is derived from termios flags and the foreground process group, never guessed.

Five states

Every response reports one of idle, running, awaiting-input, password or tui.

Password consent

It refuses to type into a password prompt without a human go-ahead.

Nonce-signed marks

A program can’t forge itself a clean exit code.

Spoof reporting

A bad mark is ignored and surfaced as spoofed_marks.

Terminal-agnostic

Not an emulator, and not a patch to yours.

States
Five states — what each means, what to do next
StateWhat it meansWhat to do
idleThe shell sits at a prompt with nothing running.Send the next command.
runningA foreground command is still executing.Poll until it completes.
awaiting-inputThe program is blocked on a line of stdin.Send the input it asked for.
passwordA hidden prompt is active with terminal echo disabled.Get human consent before typing.
tuiA full-screen application owns the screen buffer.Drive it with keys, not commands.

Black Diamond Brawl

A downhill snowboarding combat racer.

Road Rash on a snowboard — one seeded procedural slope, a finish line, and rivals who’d rather you didn’t reach it.

EnginePhaser 3
LanguageTypeScript
BuildVite
RendererSegment-based pseudo-3D
Statusv1 complete / 9 phases

Reposidyellur/black-diamond-brawl

Every sprite, gradient and weather effect is drawn in code at boot.

Matrix
Nine behaviours
One label  ·  One sentence
Seeded slopes

Every run is a fixed-length procedurally generated course ending at a finish line.

Trick air

Moguls and hill crests launch you automatically at speed.

Combat mid-race

Shove or ski-pole your way past AI rivals on the same course.

Scoring

Finish fast, land hits, thread near-misses, stomp tricks.

Wipe out

Crash hard before the line and the run ends early.

Pseudo-3D renderer

Segment-based projection, the OutRun and Road Rash lineage.

Art in code

Every sprite and gradient is generated at boot, with no image files at all.

Contrast build gate

The build fails below ΔL* 12 on gameplay edges or ΔL* 25 on sprite outlines.

Headless sim

Balance is verified by a seeded combat simulation, without a browser.
