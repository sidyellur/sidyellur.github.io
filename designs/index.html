Redesign · round two · 8 candidates

Pick one.

Round one read like eight blog posts — long paragraphs stacked in one narrow column. That was a content-architecture problem, not a visual one, so these keep the same eight visual directions and rebuild the structure underneath them.

No paragraph on any page runs longer than two sentences. Depth now lives in feature grids, spec tables, chips, stat readouts and expandable rows — things you scan rather than read. Every one is still a single self-contained index.html: zero external requests, no image files, system fonts only.

Verified in a real browser, not just claimed

All eight were rendered in headless Chromium at 1440×900 and 375×780 and checked for: visible text blocks over two sentences (zero), horizontal overflow at both widths (none), console and page errors (none), external network requests (none), <img> count (zero) and a single <h1>.

One real bug turned up and was fixed: Warm Craft's state table overflowed at 375px because a bare 1fr grid track keeps a min-content floor, so its overflow-x wrapper never constrained it.

Content decisions

Full detail in CONTENT-BRIEF.md, the single source all eight were built from.

  • Featured: tether, cleat, Black Diamond Brawl — with their real technical substance, now as scannable features rather than prose.
  • Removed: the "grad student seeking roles starting 2021" framing, phone number, .edu address, skill bars, quarantine counter, 2020 resume link.
  • Left out: cue — private repo, and a concerts app rather than AI tooling.
  • Contact: GitHub and LinkedIn. Adding an email back is one line.

Still worth doing: the old index.html had a live Google Maps API key in plaintext, public in the repo's history for years. Rotate it in the Google Cloud console whichever design wins.
