About

Most of my work sits in the same place: the gap between an AI agent and the machine it is supposed to be operating. Agents forget everything between sessions, and they read terminals by scraping text that was never meant to be parsed. Both of those are fixable, so I have been fixing them. tether gives an agent durable, associative memory; cleat gives it a real persistent shell that reports structured results instead of escape-code soup.

On the side, Black Diamond Brawl is a downhill snowboarding combat racer built solo, mostly to learn how the old pseudo-3D racers actually worked. It contains no image files at all — every sprite and gradient is generated in code at boot.

tether v0.5.1 · a shared memory layer for personal agents

Python · MCP · SQLite / FTS5 · libSQL / Turso · local static embeddings

claude mcp add tether -- uvx tether-memory

An MCP server backed by a local SQLite file. Any MCP-compatible agent can remember, recall, link and forget durable notes — facts about you, your projects, your preferences — so context follows you between sessions instead of dying with each one.

  • Runs local-only with zero configuration. Point it at a hosted libSQL/Turso primary and the same file becomes an embedded replica that syncs memory across every device in near-real-time.
  • recall is hybrid: keyword results from FTS5 fused with semantic vector results, so "automobile" finds a note about your "car". The embedding model is small and static and runs locally — no network, no API key.
  • It follows an associative usage graph to related memories. Edges come from three local deterministic sources: semantic nearest-neighbours, explicit link() calls, and hebbian edges — memories recalled together get wired together over time. Every hit carries a via receipt explaining why it surfaced.
  • Recall is seed-dominant: top direct matches are locked in place and associations only fill slots below them, so turning association on never demotes a good hit.
  • The store self-organizes. A hub-curated boot index surfaces "load-bearing" memories (highest behavioral degree) alongside recent ones, and an opt-in sweep soft-archives memories that are both old and behaviorally isolated. Nothing is ever hard-deleted.
  • Optional crystallization detects dense clusters of related memories and offers them up to be named as principles. tether finds the structure; the agent supplies the words.
  • Every feature degrades cleanly to plain keyword recall. It is deliberately a convenience layer — more useful when present, never breaking the agent when degraded.
  • Returning query-centered excerpts instead of full bodies cut a recall response from 66.9KB to 2.0KB.

cleat a headless terminal layer for AI agents

Python · MCP · PTY / termios · OSC 133 · pyte

claude mcp add cleat -- uvx cleat

cleat runs a persistent shell session behind a PTY, parses its byte stream for OSC 133 shell-integration marks, and exposes it to an agent over MCP as structured results — stdout, a real exit_code, files touched — instead of raw escape-code soup.

{ "stdout": "...", "exit_code": 0, "completed": true, "state": "idle" }
  • The core insight: when you scrape a PTY, the exit code isn't in the stream at all. The shell knows $? but never prints it. cleat injects OSC 133 marks into the shells it spawns and parses them back out.
  • The session is persistent, so cd, export, activated venvs and ssh sessions all carry across calls — something a fresh subprocess per command cannot do.
  • Every response carries a state derived from termios flags and the foreground process group — facts only the process holding the PTY can read, not guessed from output timing. The states are idle, running, awaiting-input, password and tui.
  • It refuses to type into a password prompt without explicit human consent.
  • Nonce-authenticated marks. A command can print a fake OSC 133 sequence to its own stdout to forge a clean exit code. Each session gets a fresh secrets.token_hex(8) nonce embedded in every mark cleat injects; a mark with a missing or wrong k= is ignored outright and surfaced as spoofed_marks, so the agent can tell when a program lied about how it finished.
  • Terminal-agnostic. It is not a terminal emulator, and not a modification to yours.

Black Diamond Brawl v1 complete · v2 visual overhaul complete

Phaser 3 · TypeScript · Vite · segment-based pseudo-3D renderer

A Road Rash-style downhill snowboarding combat racer, built solo as a learning project. Each run is a single race down a fixed-length, seeded, procedurally generated slope ending at a finish line.

  • Dodge trees, rocks and moguls; catch trick air off moguls and hill crests (crests launch you automatically at speed); shove or ski-pole your way past AI rivals racing the same course.
  • Score comes from finishing fast, landing hits on rivals, near-misses and tricks. Wipe out hard before the line and the run ends early.
  • A classic segment-based pseudo-3D renderer gives the behind-the-rider "road rushing at you" look — OutRun / Road Rash style — with pixel art sprites.
  • All art and atmosphere is generated in code at boot. There are no image files in the repository at all. Colour is governed by a palette module and enforced by a build gate that fails if any gameplay-relevant edge drops below ΔL* 12, or any sprite outline below ΔL* 25 against the snow behind it.
  • Ships with a headless seeded combat simulation and a solvability model, so balance is verified without a browser.
